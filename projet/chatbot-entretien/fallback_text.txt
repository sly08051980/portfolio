CSS (Cascading Style Sheets) est un langage utilisé pour styliser et mettre en forme les pages HTML.
HTML structure la page en définissant son contenu et sa hiérarchie, tandis que CSS la met en forme en contrôlant les couleurs, les polices, les marges et le positionnement des éléments.
Il y a trois méthodes :

- **Interne** : `<style>...</style>` dans `<head>`.
- **Externe** : `<link rel="stylesheet" href="style.css">`.
- **En ligne** : `style="color: red;"` dans un élément HTML.
Un `id` (`#id`) est un identifiant unique, qui ne peut être appliqué qu'à un seul élément dans une page. Une `class` (`.class`), en revanche, peut être utilisée sur plusieurs éléments pour appliquer le même style à plusieurs composants.

HTML (HyperText Markup Language) est un langage de balisage utilisé pour structurer et présenter le contenu sur le web.
La balise <head> contient des métadonnées sur le document, telles que le titre, les liens vers les feuilles de style et les scripts.
La balise <head> en HTML permet d’inclure des métadonnées, des styles CSS, des scripts JavaScript et d'autres informations importantes pour la page web, facilitant ainsi son rendu, sa compatibilité et son référencement.
<div> est une balise de niveau bloc utilisée pour regrouper des éléments, tandis que <span> est une balise en ligne utilisée pour appliquer du style à une partie du texte.
La balise <a> est utilisée pour créer des liens hypertexte qui dirigent vers d'autres pages web ou des sections d'une même page.
La balise <img> permet d'inclure une image dans une page HTML, avec l'attribut src pour spécifier la source de l'image.
La balise <form> est utilisée pour créer un formulaire permettant à l'utilisateur d'entrer des données, telles que des champs de texte, des cases à cocher, ou des boutons, afin de les envoyer à un serveur pour traitement.
Un commentaire en HTML est ajouté en utilisant la syntaxe <!-- commentaire -->. Les commentaires ne sont pas affichés sur la page web.
<ol> est une liste ordonnée où les éléments sont numérotés, tandis que <ul> est une liste non ordonnée avec des puces.
Un attribut en HTML fournit des informations supplémentaires sur un élément, généralement sous la forme nom="valeur", comme href="url" pour spécifier une destination de lien.
La balise <form> est utilisée pour créer une structure permettant à l’utilisateur de saisir des informations qui seront envoyées au serveur pour traitement.
L'attribut alt fournit une description alternative de l'image pour les utilisateurs ayant une déficience visuelle ou lorsque l'image ne peut être chargée.
La balise <link> est utilisée pour lier une feuille de style CSS externe à un document HTML.
La balise <section> est utilisée pour définir une section d'un document, souvent utilisée pour regrouper des contenus thématiques.
La balise <meta> contient des informations importantes sur le document, comme la description de la page, l'encodage des caractères ou la configuration d'affichage pour les appareils mobiles, utiles pour les navigateurs et les moteurs de recherche.
La balise <header> est utilisée pour définir l'en-tête d'un document ou d'une section, généralement pour inclure des titres, des logos ou des menus de navigation.
Une liste HTML est créée avec les balises <ul> pour une liste non ordonnée (à puces) ou <ol> pour une liste ordonnée (numérotée). Chaque élément de la liste est encapsulé dans une balise <li>.
L'attribut target='_blank' indique que le lien doit s'ouvrir dans un nouvel onglet ou une nouvelle fenêtre du navigateur.
L'attribut href spécifie la destination du lien hypertexte. Il peut contenir une URL ou un ancrage interne dans la page.
Un lien interne HTML est créé en utilisant une balise <a> avec l'attribut href pointant vers l'identifiant (#id) d’un autre élément dans la même page, permettant une navigation rapide vers une section précise.
L'attribut type spécifie le type de champ dans un formulaire, comme text, password, checkbox, etc.
La balise <footer> définit le pied de page d'un document ou d'une section, généralement utilisé pour inclure des informations de copyright, des liens ou des informations de contact.
Le texte peut être centré en utilisant la balise <center> (désapprouvée) ou via le CSS avec la propriété text-align: center;.
La balise <iframe> permet d'insérer et d'afficher une autre page web ou un contenu externe directement à l'intérieur d'une page HTML existante, sous forme d'une fenêtre imbriquée.
Un tableau est créé avec la balise <table>, les lignes avec <tr>, les cellules de données avec <td> et les en-têtes de tableau avec <th>.
Un identifiant unique en HTML se définit avec l'attribut id, permettant d’identifier précisément un élément, pour le cibler avec du CSS ou du JavaScript, ou créer des ancres internes.
Un formulaire de contact est créé avec la balise <form>, en incluant des champs de saisie comme <input>, <textarea> et un bouton <button> pour envoyer le formulaire.
La balise <strong> est utilisée pour marquer du texte avec une importance particulière, généralement affichée en gras par défaut.
Pour intégrer une vidéo dans une page HTML, on utilise la balise <video> en indiquant l'attribut src pour la vidéo, avec éventuellement des balises <source> pour fournir différents formats. L'attribut controls permet d’afficher les contrôles de lecture.
L'attribut style permet d'ajouter des styles CSS directement à un élément HTML, par exemple <p style="color:red;">.
Un bouton en HTML est créé avec la balise <button>, qui peut avoir plusieurs types comme submit, reset ou button. Exemple : <button type="submit">Envoyer</button>.
Un lien de téléchargement est créé avec la balise <a> et l'attribut download, comme <a href="file.pdf" download>Download</a>.
La balise <nav> est utilisée pour définir une section de navigation contenant des liens de navigation.
L'attribut required en HTML permet de rendre obligatoire le remplissage d'un champ avant la soumission du formulaire, assurant ainsi une validation côté client intégrée directement dans le navigateur.
L'attribut placeholder permet d'afficher un texte temporaire dans un champ de saisie, avant que l'utilisateur n'y entre des données.
Le fond d'écran peut être ajouté avec CSS en utilisant la propriété background-image: url('image.jpg');.
Une balise auto-fermante n'a pas besoin de balise fermante, comme <img />, <br /> ou <hr />.
L'attribut width dans la balise <img> permet de définir la largeur d'une image en pixels ou en pourcentage, facilitant ainsi le contrôle précis de la taille et l’optimisation du rendu visuel.
Une feuille de style interne est ajoutée avec la balise <style> dans la section <head> du document.
La balise <blockquote> en HTML est utilisée pour citer des passages longs provenant d'une autre source, en indiquant clairement qu'il s'agit d'une citation externe ou d’un contenu repris.
<b> rend le texte en gras sans indiquer d'importance particulière, tandis que <strong> met l'accent sur le texte en indiquant qu'il est important.
Une barre de défilement est ajoutée avec CSS, par exemple overflow: auto; ou overflow: scroll;.
L'attribut charset spécifie l'encodage des caractères utilisé par la page HTML, assurant que les navigateurs affichent correctement les caractères spéciaux ou internationaux, comme par exemple avec <meta charset="UTF-8">.

La programmation impérative décrit comment exécuter des opérations étape par étape, tandis que la programmation déclarative spécifie le résultat souhaité sans détailler les étapes d’exécution.
Un algorithme est une série finie d’instructions ou d’étapes logiques permettant de résoudre un problème ou d’accomplir une tâche spécifique.
La POO est un paradigme de programmation qui organise le code autour d’objets, regroupant données et comportements, et favorise l’héritage et l’encapsulation.
L’héritage permet à une classe (sous-classe) de réutiliser, étendre ou modifier le comportement d’une autre classe (superclasse).
Un langage compilé est transformé en code machine avant l’exécution, tandis qu’un langage interprété est lu et exécuté ligne par ligne par un interpréteur.
L’encapsulation consiste à regrouper des données et leurs méthodes associées dans une même entité (classe) et à restreindre l’accès direct aux attributs pour protéger l’intégrité des données.
Une fonction est un bloc de code réutilisable qui effectue une tâche spécifique et qui peut retourner une valeur après son exécution.
Une procédure effectue des actions sans nécessairement retourner une valeur, tandis qu’une fonction renvoie une valeur après traitement.
Une variable est un espace de stockage nommé qui contient une valeur pouvant être modifiée durant l’exécution du programme.
Une variable locale est accessible uniquement dans le bloc ou la fonction où elle est définie, tandis qu’une variable globale est accessible dans l’ensemble du programme.
Un tableau statique a une taille fixe définie à la compilation, alors qu’un tableau dynamique peut être redimensionné pendant l’exécution du programme.
Une structure de contrôle permet de diriger le flux d’exécution du programme (par exemple, les boucles, les conditions).
Une boucle « for » permet d’itérer sur une séquence de valeurs pour exécuter une série d’instructions de manière répétée. Par exemple, parcourir tous les éléments d’un tableau.
Une instruction conditionnelle permet d’exécuter du code uniquement si une certaine condition est vraie (par exemple, l’instruction « if »).
Le débogage est le processus de recherche et de correction des erreurs ou bugs dans un programme.
On peut utiliser des environnements de développement intégrés (IDE) avec des débogueurs intégrés, des impressions dans la console (logs) ou des outils de profilage.
Le versionnage de code consiste à utiliser des systèmes de gestion de versions comme Git pour suivre l’évolution du code, faciliter la collaboration et gérer les modifications.
Le merge est l’opération qui combine les modifications apportées sur différentes branches dans une branche commune.
En examinant manuellement les fichiers conflictuels, en décidant quelles modifications garder et en résolvant les conflits avant de valider le merge.
Un commit est une sauvegarde enregistrée du code dans l’historique du dépôt, représentant un ensemble de changements apportés.
Les tests unitaires permettent de vérifier que chaque partie du code fonctionne correctement et facilitent la détection et la correction d’erreurs lors de modifications ultérieures.
Une API (Application Programming Interface) est un ensemble de règles et de protocoles permettant à différentes applications de communiquer entre elles.
JSON est un format de données léger utilisé pour échanger des données entre un serveur et une application web.
JSON est généralement plus léger et facile à lire pour les humains, tandis que XML est plus verbeux et structuré pour les documents hiérarchiques.
Une base de données est un ensemble organisé de données structurées, souvent géré par un système de gestion de bases de données.
Le SQL (Structured Query Language) est un langage utilisé pour interagir avec les bases de données relationnelles (interrogation, insertion, mise à jour, suppression de données).
Une base relationnelle utilise des tables avec des relations strictes entre elles, tandis que les bases NoSQL sont souvent plus flexibles et adaptées aux données non structurées.
Une jointure en SQL permet de combiner des enregistrements de deux ou plusieurs tables en se basant sur une condition commune entre elles.
Un index est une structure de données qui améliore la vitesse de récupération des données dans une table, au détriment d’un coût supplémentaire lors des mises à jour.
L’optimisation de requêtes SQL consiste à améliorer les performances des requêtes en réduisant le temps de réponse, par exemple en utilisant des index ou en réécrivant la requête.
Un bug est une erreur ou un défaut dans le code qui provoque un comportement inattendu ou incorrect d’un programme.
Les commentaires facilitent la compréhension, la maintenance et la collaboration sur le code en expliquant la logique et les intentions derrière certaines implémentations.
Ils permettent de marquer des zones du code nécessitant des améliorations ou des ajouts futurs, facilitant ainsi la planification des tâches de développement.
Un IDE est un logiciel qui regroupe des outils de développement comme un éditeur de code, un débogueur, un compilateur pour faciliter l’écriture et la gestion du code.
Visual Studio Code, Eclipse, IntelliJ IDEA sont parmi les IDE les plus utilisés.
Le contrôle de version permet de suivre les modifications, de faciliter la collaboration et de revenir à des versions antérieures en cas de problème.
Un commit message efficace décrit clairement les changements apportés, les raisons de la modification et le contexte pour les autres membres de l’équipe.
Elles facilitent la maintenance, améliorent la lisibilité et réduisent les risques d’erreurs, surtout dans des projets collaboratifs.
La documentation technique décrit le fonctionnement du code, les architectures utilisées et les processus, ce qui facilite la compréhension et la maintenance du projet par d’autres développeurs.
Une bibliothèque est un ensemble de fonctions et de ressources pré-écrites qui peut être intégré dans un projet pour faciliter le développement.
Un framework est un ensemble d’outils et de conventions qui fournit une structure de base pour développer des applications, facilitant ainsi le développement et la maintenance.
Une bibliothèque fournit des fonctionnalités à utiliser au besoin, tandis qu’un framework impose une architecture et contrôle le flux d’exécution de l’application.

Un middleware est un logiciel intermédiaire qui gère la communication et la gestion des données entre différentes applications ou entre la couche serveur et le client.

Un pull request est une demande de fusion de modifications apportées sur une branche vers une branche principale, généralement accompagnée d’une révision par les pairs.
